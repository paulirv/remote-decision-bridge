Common Workflows

Start a New Project


/spec vision              # Optional: define why
/spec create              # Required: define what
/spec approve             # Lock in the spec
/requirement propose      # Create requirements from capabilities
/requirement approve REQ-0001
/backlog add              # Build the backlog
/risk assess              # Identify initial risks

Daily Development


/standup                  # Morning status
/sprint status            # Check progress
... work ...
/requirement update-ac REQ-0001 AC-01 complete
/sprint complete <item>   # When done

End of Sprint


/sprint review            # What was delivered
/retrospective            # What to improve
/sprint start             # Begin next sprint

Release


/release plan             # Define what's shipping
/release prepare          # Verify readiness
/release checklist        # Create deployment steps
/release deploy           # Ship it
